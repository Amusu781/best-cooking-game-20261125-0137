Lantern Alley Kitchen is a cooking game set in a lantern-lit night-market noodle and bao stall. Ten ingredients each have their own prep path: chop, grill, boil or steam, with a burn window. You combine them into eight dishes on assembly mats and serve them at the pass before each ticket's patience runs out, across five 3:00 services that get faster each night, with a rush combo, lantern stars and an upgrade shop between days. Walk with WASD or the arrow keys, press E or Space to pick up, put down and use, and hold E (or the mouse) on a board to chop. You can also click any station and the chef walks there and uses it. P pauses, M mutes.

## Run it

```sh
node serve.ts   # then open http://localhost:8080
MAKEFUN_OUTPUT_DIR=out node main.ts
```
